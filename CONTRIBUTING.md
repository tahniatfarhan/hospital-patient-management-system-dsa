# Contributing Guidelines

Thank you for your interest in contributing to this C++ Data Structures & Algorithms project!

## Build & Test Workflow

1. Configure CMake build:
   ```bash
   mkdir build && cd build
   cmake ..
   ```
2. Build executable & test suite:
   ```bash
   make
   ```
3. Run C++ unit test suite:
   ```bash
   ctest --output-on-failure
   ```
