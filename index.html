Project Overview

Understanding the background, rationale, and target engineering domain.

What It Is

A high-performance C++ data structures system comparing unbalanced BSTs against self-balancing AVL trees.

Why It Was Built

Built to demonstrate algorithmic performance optimization, height-balancing, and RAII dynamic memory cleanup.

Real-World Problem

Prevents O(N) linear time degradation on sorted patient ID insertions by enforcing O(log N) tree balance.

What I Personally Implemented

Specific engineering contributions, architecture design, and features developed by Tahniat Farhan.

Modularized monolithic C++ implementation into clean headers (`include/BST.hpp`, `include/AVLTree.hpp`).
Implemented self-balancing AVL tree Left/Right rotations maintaining O(log N) worst-case lookup time.
Added RAII post-order recursive destructors (`~BST()`, `~AVLTree()`) guaranteeing zero dynamic memory leaks.
Created CMake build pipeline with automated unit tests benchmarking BST vs AVL performance.
